## Project Overview

Braam Bakehouse is a fictional bakery created for this website
development project. The website provides information about the
bakery and its products and allows customers to make enquiries.

## Website Goals and Objectives

The main goal of the website is to create a professional online
presence for Braam Bakehouse.

The objectives are to:
- Provide information about the bakery.
- Display the available products.
- Allow customers to make enquiries.
- Provide contact information.
- Create a simple and easy-to-use website.

## Key Features and Functionality

The website contains five main pages:

- Home
- About Us
- Products
- Enquiry
- Contact

The website also includes:
- Navigation links
- Product images
- Enquiry form
- Contact information
- Buttons
- Responsive and organised page layouts
